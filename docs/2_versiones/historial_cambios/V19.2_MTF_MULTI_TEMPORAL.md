## Resumen Ejecutivo

El TrendWorker operaba exclusivamente en M1 (1 minuto), lo que provocaba entradas contra la estructura de timeframes superiores — comprar en un techo de H4 porque M1 mostraba señal alcista momentánea.

Se implementó un análisis Top-Down profesional de 3 pantallas (H4 → H1 → M5) donde cada temporalidad cumple un rol específico. El Sniper (StructureWorker) se migró de M1 a M15 para detectar niveles institucionales reales.

**Regla cardinal:** H4 siempre manda la dirección. Si M5 contradice H4, la señal se penaliza un 70%.

---

## Problema Diagnosticado

### Antes (single-timeframe M1)

| Worker | Timeframe | Indicadores | Problema |
|---|---|---|---|
| TrendWorker | M1 (100 velas = 1.6h) | EMA 9/21 + RSI 14 | Visión de túnel: no ve estructura macro |
| Sniper | M1 (300 velas = 5h) | BOS, OB, FVG | Micro-ruido: fractales de M1 no son niveles institucionales |
| Hurst | M1 (1024 velas = 17h) | Exponente de Hurst | Sin cambios |

**Efecto:** El bot compraba pullbacks temporales de M1 dentro de tendencias bajistas de H4. Operaba contra la marea sin saberlo.

### Ejemplo real del fallo
```
H4: Tendencia bajista, RSI=38, EMA50 cayendo
M1: Micro-rebote de 10 pips, EMA9 cruza EMA21 al alza
Bot: COMPRA (Trend vota +0.5) → pierde por rebote estructural de H4
```

## Arquitectura MTF Implementada

### Cascada Top-Down

```
┌────────────────────────────────────────────────┐
│  H4 — SESGO DIRECCIONAL (La Marea)             │
│  EMA50 pendiente + RSI14                        │
│  Decide qué lado del mercado es permitido       │
│  Caché: 4 horas                                 │
├────────────────────────────────────────────────┤
│  H1 — MOMENTUM DE SESIÓN (La Ola)              │
│  MACD (12,26,9) histograma                      │
│  Confirma o penaliza alineación con H4          │
│  Caché: 1 hora                                  │
├────────────────────────────────────────────────┤
│  M15 — ESTRUCTURA INSTITUCIONAL (El Sniper)     │
│  SMC: BOS + Order Blocks + FVG                  │
│  Zonas de entrada con significado real           │
│  Caché: 15 minutos (sin cambios)                │
├────────────────────────────────────────────────┤
│  M5 — GATILLO DE ENTRADA (El Disparo)           │
│  EMA9 + vela direccional                        │
│  Solo confirma timing, NUNCA decide dirección   │
│  Sin caché (cada ciclo de 60s)                  │
└────────────────────────────────────────────────┘
```

### Por qué estas temporalidades

| TF | Por qué SÍ | Por qué no otra |
|---|---|---|
| **H4** | Captura tendencia de 2-5 días. EMA50 responde en tiempo real. | MACD en H4 es inútil: 26×4h = 104h para reaccionar (demasiado lento) |
| **H1** | TF óptimo para MACD en Forex intraday (26h respuesta). Captura sesiones London→NY. | En M15 el MACD genera demasiadas señales falsas |
| **M15** | BOS/OB/FVG representan niveles donde las instituciones dejaron órdenes. | En M1 los fractales son micro-ruido sin significado |
| **M5** | Filtra el 80% de señales falsas de M1. Cruces EMA: 2-4/sesión vs 10-15 en M1. | M15 para gatillo es demasiado lento (10-15 pips de retraso) |
| ~~M1~~ | **Eliminado.** No aporta nada que M5 no haga mejor. | RSI y MACD en M1 son ruido puro |

## Cambios Técnicos Detallados

### 1. `workers/worker_trend.py` — Reescritura completa

**Antes:** 140 líneas, single-timeframe M1, EMA 9/21 + RSI 14.
**Ahora:** 230 líneas, MTF 3-pantallas con cachés.

#### Pantalla H4: `_analizar_h4()`
- **Indicadores:** EMA 50 (pendiente sobre 5 velas = 20h) + RSI 14
- **Velas pedidas:** 60 en `TIMEFRAME_H4`
- **Lógica de sesgo:**

| Condición | Sesgo |
|---|---|
| EMA50 subiendo (slope > 0.01%) + RSI < 65 | +0.30 (alcista sano) |
| EMA50 subiendo + RSI 65-78 | +0.15 (alcista maduro) |
| EMA50 subiendo + RSI > 78 | 0.00 (sobrecompra → bloqueo soft) |
| EMA50 bajando (slope < -0.01%) + RSI > 35 | -0.30 (bajista sano) |
| EMA50 bajando + RSI 22-35 | -0.15 (bajista maduro) |
| EMA50 bajando + RSI < 22 | 0.00 (sobreventa → bloqueo soft) |
| Slope entre -0.01% y +0.01% | 0.00 (lateral) |

- **Caché:** 4 horas por símbolo (dict de clase `_cache_h4`)

#### Pantalla H1: `_analizar_h1()`
- **Indicador:** MACD histograma (implementación directa con `ewm()`, sin dependencia extra)
- **Velas pedidas:** 50 en `TIMEFRAME_H1`
- **Retorna:** `(multiplicador: float, alineado: bool)`
- **Lógica de alineación con H4:**

| Histograma MACD | H4 alcista | H4 bajista | H4 lateral |
|---|---|---|---|
| Positivo + creciendo | Alineado, mult=1.0 | **NO alineado**, mult=0.7 | Alineado, mult=1.0 |
| Positivo + decreciendo | Alineado, mult=0.8 | Alineado, mult=0.8 | Alineado, mult=0.8 |
| Negativo + creciendo | Alineado, mult=1.0 | Alineado, mult=1.0 | Alineado, mult=1.0 |
| Negativo + decreciendo | **NO alineado**, mult=0.4 | Alineado, mult=0.8 | Alineado, mult=0.8 |

- **Caché:** 1 hora por símbolo (dict de clase `_cache_h1`)

#### Pantalla M5: `_analizar_m5()`
- **Indicadores:** EMA 9 + EMA 21 (parámetros configurables desde BD)
- **Velas pedidas:** 50 en `TIMEFRAME_M5`
- **Lógica simplificada (solo timing):**

| Condición | Voto |
|---|---|
| Precio > EMA9 > EMA21 + vela alcista | +0.80 |
| Precio > EMA9 > EMA21 (sin vela alcista) | +0.50 |
| Precio < EMA9 < EMA21 + vela bajista | -0.80 |
| Precio < EMA9 < EMA21 (sin vela bajista) | -0.50 |
| Precio > EMA9 (sin stack completo) | +0.20 |
| Precio < EMA9 (sin stack completo) | -0.20 |
| EMAs comprimidas (distancia < 0.01%) | Voto × 0.5 |

- **RSI eliminado de M5** — es ruido en esta temporalidad.
- **Sin caché** — se ejecuta cada ciclo de 60 segundos.

#### Lógica de Combinación: `_calcular_voto_mtf()`
```python
if sesgo_h4 != 0:
    if M5 contradice H4:
        voto = voto_m5 * 0.3          # Penalización del 70%
    else:
        voto = voto_m5 * mult_h1 + sesgo_h4   # Alineado
else:
    voto = voto_m5 * 0.5              # H4 lateral → descuento 50%

voto_final = clamp(voto, -1.0, +1.0)
```

#### Interfaz de retorno (compatible con Manager)
```python
{
    'voto': float,        # [-1.0, +1.0] — voto final MTF
    'ema_fast': float,    # EMA9 de M5
    'ema_slow': float,    # EMA21 de M5
    'rsi': 0.0,           # Siempre 0 (RSI eliminado de M5)
    'precio': float,      # Precio cierre actual M5
    'sesgo_h4': float,    # Sesgo H4 [-0.30, +0.30]
    'mult_h1': float,     # Multiplicador H1 [0.4, 1.0]
    'estado_mtf': str,    # Ej: "H4:ALCISTA(+0.30) H1:x0.8 M5:+0.50"
}
```

#### Constantes de Timeframe
Definidas localmente para evitar importar MetaTrader5 en el worker:
```python
_TF_M5 = 5       # mt5.TIMEFRAME_M5
_TF_H1 = 16385   # mt5.TIMEFRAME_H1
_TF_H4 = 16388   # mt5.TIMEFRAME_H4
```

### 2. `workers/worker_structure.py` — Migración a M15

| Aspecto | Antes | Ahora |
|---|---|---|
| Timeframe | M1 (300 velas = 5h) | M15 (200 velas = 50h) |
| Proximidad OB | 0.05% (~5 pips EURUSD) | 0.15% (~15 pips EURUSD) |
| Import | `import MetaTrader5 as mt5` (no usado) | Constante local `_TF_M15 = 15` |
| Lógica SMC | Sin cambios | Sin cambios |
| Caché | 15 minutos (sin cambios) | 15 minutos (sin cambios) |

**Justificación:** Los fractales de M1 (BOS, Order Blocks, FVG) son micro-ruido. En M15:
- Un BOS representa ruptura de 4+ horas de acumulación
- Un Order Block es una zona donde las instituciones dejaron órdenes pendientes
- Un FVG refleja un desequilibrio real de oferta/demanda

La proximidad del OB se amplió porque los Order Blocks en M15 son zonas más anchas (~15-20 pips en Forex majors vs ~5 pips en M1).

## Impacto en Performance

| Recurso | Antes | Ahora | Delta |
|---|---|---|---|
| Llamadas MT5 por símbolo/ciclo | ~6 (todo M1) | ~6 (cachés H4/H1) | ≈ 0 |
| Datos extra descargados | 0 | +50 velas H1 + 60 H4 (cacheados) | Mínimo |
| Tiempo de cálculo por símbolo | ~200ms | ~250ms | +50ms |
| RAM extra por símbolo | 0 | ~2KB (cachés H4+H1) | Despreciable |

Las llamadas H4 y H1 se cachean agresivamente. En un ciclo de 60 segundos, la mayoría de las veces se usa la caché → cero calls extra a MT5.

## Flujo de Decisión Completo

```
¿H4 tiene sesgo definido?
├─ NO (lateral) → Multiplicador ×0.5 a todo. Operar con cautela.
├─ SÍ: VENTA (sesgo < 0)
│   ├─ ¿H1 confirma? (MACD hist negativo o decreciendo)
│   │   ├─ SÍ → mult 0.8-1.0. Buscar SHORT en M15 zona + M5 gatillo.
│   │   └─ NO → mult 0.4-0.7. Pullback en curso. Señal muy débil.
│   └─ ¿M5 quiere COMPRAR? → Contra-tendencia: penalización 70%.
│       El bot NUNCA buscará un LONG contra H4 bajista.
└─ SÍ: COMPRA (sesgo > 0)
    └─ (espejo exacto)
```
