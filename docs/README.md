# Aurum — Centro de Conocimiento (Docs Index)

Bienvenido al cerebro documental de Aurum. Esta estructura está diseñada para facilitar la navegación tanto a humanos como a agentes de Inteligencia Artificial.

---

## 📂 Organización de Directorios

### [1. Arquitectura](file:///c:/www/Aurum/docs/1_arquitectura/)
Planos técnicos y manuales sobre el funcionamiento interno.
- **core/**: Lógica fundamental del motor.
- **manuales/**: Guías completas del sistema.
- **componentes/**: Detalle de bases de datos, frontend y scripts.
- **infra/**: Configuración de servidores y GCP.

### [2. Versiones](file:///c:/www/Aurum/docs/2_versiones/)
Historial evolutivo y guías de actualización.
- **historial_cambios/**: Registro detallado de versiones.
- **migraciones/**: Scripts SQL y planes de parcheo.

### [3. Análisis](file:///c:/www/Aurum/docs/3_analisis/)
Inteligencia aplicada y resultados de rendimiento.
- **trades/**: Análisis de debilidades y deep-dives de operaciones.
- **laboratorio/**: Reportes de simulación y tests.
- **estrategia/**: Experimentos con filtros y configuraciones.
- **auditorias/**: Revisiones de seguridad y calidad.

### [4. Gestión](file:///c:/www/Aurum/docs/4_gestion/)
Día a día operativo y comunicación.
- **incidencias/**: Seguimiento de bugs.
- **roadmaps/**: Tareas pendientes y visión de cliente.
- **comunicaciones/**: Protocolos para agentes y operaciones remotas.

---

> [!TIP]
> Si eres un agente nuevo, comienza leyendo `docs/1_arquitectura/core/AURUM_ARCHITECTURE.md` para entender el ecosistema antes de proponer cambios.
